Each language step runs on NVIDIA Nemotron through Meterless Nightshift on this Mac, and you can see which model answered and how long it took. |

Nemotron writes the explanation, but it never writes a number. It writes placeholders, Kilowhy fills them from the evidence, and a verifier checks every figure before the answer appears.
